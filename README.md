# Weekly Meal Planner

 **Work in Progress**

A lightweight Python application designed to manage recipes and organize weekly meal plans. The program currently uses a local JSON database to store, read, and append new recipes.

## Features
* **Recipe Management:** Add new meals and read existing ones directly from the database.
* **Local Storage:** Uses a standard JSON file (`recipes.json`).
* **Weekly Generator:** *(Upcoming)* Automated selection and distribution of meals to create a balanced weekly menu.
